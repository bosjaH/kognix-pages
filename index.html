Hermes Google Access

A private, single-user automation tool.

What this application is

Hermes Google Access is a personal command-line tool that runs on one person's own computer. It is not a service, it has no sign-up, and it is not distributed to or used by anyone else. It authenticates as its owner and no one else.

What it does

With the owner's explicit authorization, the tool reads the owner's own Google Calendar and Gmail once each morning and prints a short summary — the day's appointments and any message that appears to need attention — in the owner's terminal and private chat. It is read-only in practice: it sends no mail, changes no event, and shares nothing with anyone.

Google user data

The tool requests only read access to Google Calendar and Gmail, plus the minimum additional scopes needed to reach those APIs. Data is processed on the owner's own machine, stored only there, and never transmitted to the developer or to any third party. For the details, see the privacy policy.
